# R.P.D. — Gerçek Android Uygulaması v0.1

Bu proje Android için hazırlanmış gerçek APK kaynak projesidir. PWA değildir.

İlk sürüm arayüzü: Ana Sayfa, Keşfet, Gruplar, Mesajlar, Profil, karakterler, profil düzenleme ve tema altyapısı.

## APK
`.github/workflows/build-apk.yml` GitHub Actions üzerinde Android SDK ve Gradle kurarak debug APK üretir.

## Sonraki aşama
Gerçek kullanıcı hesapları, benzersiz @nick, sunucu/API, veritabanı, medya depolama, takip, mesajlaşma, bildirimler ve moderasyon eklenecek.
